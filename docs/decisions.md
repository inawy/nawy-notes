## 2026-10-01 · منتج مستقل بنمط TypeScript + Vite + Tailwind (بدون React بعد)
- **السبب:** نموذج أولي صغير لتطبيق ملاحظات على غرار Keep؛ أقل اعتماديات ممكنة.
- **مرفوض:** React الآن (لا حاجة قياسية بعد)، إعادة كتابة تطبيق ناوي الحالي (يمنعها nawy-quality).
- **الحالة:** نموذج للمراجعة. لم يُدمج في تطبيق ناوي الحالي.

## 2026-10-01 · استثناء مؤقت: نسخة الملف الواحد تحمّل مكتبات من CDN
- **القاعدة المخالَفة:** "لا شيفرة تشتغل من CDN" (nawy-architecture).
- **السبب:** بيئة الإنشاء بلا npm، ونريد مراجعة الشكل بملف واحد قبل البناء.
- **قيد:** للمراجعة فقط، لا تُنشر. الإصدار = `npm run build` (كل شيء مجمّع محلياً).
- **الحالة:** مؤقت؛ يُغلق عند اعتماد البناء.

## 2026-10-01 · استثناء: ترحيل v2 كسول بدل upgrade()
- **القاعدة المخالَفة:** nawy-data (كل تحويل بيانات = version جديد + upgrade() + اختبار).
- **ما حدث:** `version(2)` بنفس الفهارس، والتحويل (draw/audio/image → مرفقات) يتم عند القراءة في `normalizeNote` ويُحفظ مع أول تعديل. لم تُعدَّل كتلة `version(1)`.
- **السبب:** upgrade() كان مشتبهاً به في تعطّل فتح قاعدة موجودة عند المستخدم (غير مؤكد).
- **الحالة:** يلزم إعادة النظر: إما upgrade() حقيقي مع fixture، أو توثيق الكسل نهائياً.

## مخالفات معروفة لم تُعالَج بعد
- صيغة التصدير ليست مغلف nawy الموحّد (`app:"nawy"`, `schemaVersion`, `data`)، والاستيراد لا يرفض إصداراً أحدث، ولا يعرض دمج/استبدال ولا يلتقط نسخة قبل الاستبدال.
- الواجهة تستدعي Dexie مباشرة (main.ts/editor.ts) بلا طبقة services/ports.
- لا طبقة ترجمة؛ النصوص مكتوبة داخل المكوّنات.
- أهداف اللمس 36px (المطلوب 44px)؛ استعمال `mr-*`/`left-1/2` بدل الخصائص المنطقية؛ لا حبس للتركيز في النوافذ؛ القوائم تُخفى بـ display بدل transform.
- Service Worker على `autoUpdate` (قد يعيد التحميل أثناء التحرير؛ المطلوب مطالبة "التحديث جاهز").
- لا lockfile ولا اختبارات داخل المستودع (الاختبارات المنفَّذة كانت سكربتات مؤقتة خارجه).
- لا تحقق بمتصفح حقيقي ولا بـ Dexie الحقيقية.

## 2026-10-01 · التعايش مع تطبيق ناوي على نفس النطاق
- **القرار:** ناوي نوت منتج مستقل بهوية ناوي، يُنشر في مسار فرعي (مثل `/notes/`) ويمكن دمجه لاحقاً.
- **العزل:** قاعدة `nawy-note-db`؛ مفاتيح localStorage بالبادئة `nawy-note:`؛ ذاكرة SW بالبادئة `nawy-note-`؛ نطاق الـ SW ومعرّف المانيفست خاصان بالمسار.
- **إصلاح:** كان `sw.js` يحذف كل الذاكرة المؤقتة غير ذاكرته (كان سيمسح ذاكرة ناوي)؛ صار يحذف فقط ما يبدأ بـ `nawy-note-`.
- **للدمج لاحقاً:** مشاركة الثيم/الهوية والتصدير الموحّد تُقرَّر عند الدمج؛ لا مفاتيح مشتركة الآن عمداً.
